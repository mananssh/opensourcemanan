# ARCD — design brief: "Floor"

`/games` vertical branded **ARCD** (arcade). Deliberate diverge from Editorial /
Reel / Vault. Built around a licensed unDraw hero illustration — not line-art
icons or emoji.

## Direction

Quiet **floor**: generous space, one wordmark, one illustration, one CTA.
Dark charcoal + rose accent. The unDraw “Gaming Controller” scene is the visual
anchor (person + dual sticks) — the brand is typography + that art, nothing else
in the first viewport.

# Mood roulette

Use when the feature brief is thin or you feel yourself drifting toward
Editorial cream/ink. **Pick one row that fits the subject**, then invent
concrete hexes and type — do not copy another vertical's tokens.

Do **not** land on "warm paper editorial" unless you are designing the home
Editorial Logbook itself.

## How to spin

1. Map the feature to a **feeling** (pace, temperature, era, material).
2. Choose the closest row — or mash two rows into a new phrase.
3. Write that phrase at the top of `docs/design/<slug>.md`.
4. Fill the token table from scratch. **Never** start by copying
   `.vertical-blog`, `.vertical-games`, `.vertical-vault`, etc.

## Sibling verticals (anti-goals — do not echo)

When listing anti-goals in the brief, name at least one real sibling:

- Editorial Logbook (home) — warm paper, Fraunces/Newsreader, oxblood
- Blog — Kinetic Mono / vermilion
- Dump — cool board / Caveat
- Portfolio — monochrome Bricolage
- Movies / Reel — VHS magenta/cyan
- Vault — steel + brass
- Games / ARCD — Cabinet After Hours / phosphor + marquee

New work should be **visibly not** those.
